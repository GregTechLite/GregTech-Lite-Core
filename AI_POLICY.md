# AI Usage Policy

This policy defines how we expect contributors to use AI tools in this repository.
It supplements [CODE_OF_CONDUCT.md][CodeOfConduct] and [CONTRIBUTING.md][Contributing].

We welcome the use of AI to help with development. At the same time, AI-assisted or AI-generated
work is subject to stricter review than work produced without AI. Using AI does not lower the
quality bar, and it does not transfer responsibility away from the contributor.

## Contributors Must Fully Understand the Code

Anyone submitting AI-assisted work must fully understand the code they submit.
Before requesting review, the contributor must be able to:

- Explain what the change does and why it is correct;
- Explain the control flow, error handling, concurrency behavior, and edge cases;
- Justify design decisions without relying on “the AI suggested it”;
- Respond to questions from maintainers about any part of the change.

Contributors must also actively respond to change requests from maintainers. Ignoring review
comments, responding vaguely, or pushing unexplained AI-generated revisions is not acceptable.
If a maintainer requests a change, the contributor is expected to engage with the request
substantively and promptly.

## Do not use AI to Reprocess Logs for Issue Reports

When filing an issue, do not use AI to summarize, rewrite, filter, reformat, or otherwise
reprocess log content.

Submit logs and diagnostic output according to the requirements in [CONTRIBUTING.md][Contributing].
Maintainers need the original log content, not an AI-processed interpretation of it.

## Enforcement

Maintainers may:

- Request additional justification or tests for AI-assisted changes;
- Ask the contributor to explain any part of the submitted code;
- Close or return pull requests that do not meet this policy;
- Restrict contributions from contributors who repeatedly ignore this policy.

This policy is intentionally simple. When in doubt, follow [CONTRIBUTING.md][Contributing], ask
maintainers before submitting, and remember that the human contributor — not the AI tool — is
responsible for the contribution.
